# Finds & Choices GH — Repository Notes

## Open the actual shopping website

**Published storefront:** https://kaylee7-ai.github.io/Finds-Choices-GH/

This README is documentation for the GitHub repository. It is not the shopping website. To see the storefront, open the published link above.

## Website files

- `index.html` — the customer-facing shopping website and its five product cards.
- `README.md` — these repository notes.

The homepage file must remain named exactly `index.html` and stay in the repository root on the `main` branch for GitHub Pages to serve it as the site homepage.

## Current catalogue

The homepage currently contains five Tezeon product listings:

1. Mirror iPhone case with rhinestone-style frame.
2. 10-in-1 USB-C docking station hub.
3. Magnetic protective iPhone case with fold-out ring.
4. Premium PU leather-look iPhone case with stand.
5. External CD/DVD drive.

Prices and stock can change. Customers should confirm current product details, variants, delivery charges and return terms on the retailer's product page.

## Product links and affiliate disclosure

The current product buttons open ordinary Tezeon product pages. They are not being represented as commission-tracked links. Only replace them with tracking URLs issued to an eligible, approved account holder after the account arrangement and image-use permissions have been confirmed.

## Updating products

At present, the product cards are embedded in `index.html`. Adding or changing products requires editing that file and committing the change to `main`. A Google Sheets-based catalogue connection has not yet been configured.

## GitHub Pages

The expected Pages configuration is:

- Branch: `main`
- Folder: `/(root)`
- Homepage file: `index.html`

After a commit, allow GitHub Pages to deploy, then open the published storefront link above and refresh the page.

## Important operating distinctions

- **Affiliate listing:** Customers buy from the external retailer. A valid, approved affiliate tracking link is required for commission attribution.
- **Resale listing:** The store operator is responsible for the customer-facing sale, fulfilment, delivery terms and returns. Do not activate resale checkout until the adult business operator has confirmed the supplier arrangement and applicable permissions.
- **Privacy:** This static website does not collect customer details or payments. Do not add order forms or collect personal information until a lawful, secure order and privacy process is in place.
